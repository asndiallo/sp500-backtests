# Phase 1–3 sources: provenance, extraction method, known defects

Every row of `data/largest_company_by_quarter.csv` cites the sources below (`source_url` + `anchors`
columns). Files marked **(script)** are regenerated by `python scripts/fetch_sources.py`; the others came
from browser-only or manual extraction and are committed as-is, with the method recorded here.

## Market-cap rankings

> **Not in the public repository:** `companiesmarketcap_history.csv` (a scraped vendor dataset) and
> `derived_quarter_end_market_caps.csv` (the same values resampled to quarter-ends) are git-ignored to avoid
> republishing companiesmarketcap.com's data. Regenerate them with `python scripts/fetch_sources.py cmc`
> followed by `python scripts/build_top_table.py`. Everything else, including the Phase 1 table built from
> them, is committed.

**Top-20 candidates (Phase 7).** 27 surviving S&P 500 names that could plausibly rank in the top 20 after 2009 were added to `data/universe.csv` ("Top-20 candidate" in `continuity_note`). Their companiesmarketcap histories were fetched with `python scripts/fetch_sources.py cmc_missing`, which appends only tickers absent from the local history and leaves every earlier scrape untouched. `scripts/build_top_table.py` then writes `data/top20_by_quarter.csv`. Rebuilding with the extra names left the #1 table and every top-10 list unchanged.

**Rejected source:** finhacker.cz "Largest 20 S&P 500 companies 1989–2026". It has no GE at all and shows Coca-Cola as #1 in 1996–97, so it is visibly built from today's constituents (survivorship-biased). Not used.

**Revenue rankings are not used as market-cap evidence.** Fortune 500 figures surfaced by some searches (e.g. UPI 1990-04-03, "GM, Ford, Exxon, IBM still top the list") are revenue-based and were excluded.

## Access notes

- Stooq could not be used as a fallback: pandas-datareader 0.11 removed its Stooq reader, and stooq.com now gates downloads behind a JavaScript proof-of-work bot check, which this project does not circumvent.
- Morgan Stanley, S&P Global and the AT&T IR site block non-browser clients; they were read in a normal browser session.
